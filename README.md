# Registration

Демонстрационная страница регистрации пользователя на HTML, CSS и JavaScript.

## Возможности
- Проверка имени, формата электронной почты и совпадения паролей.
- Минимальная длина пароля в форме — 12 символов.
- Кнопки показа/скрытия пароля.
- Адаптивная вёрстка и доступные сообщения об ошибках.
- Персональные данные не отправляются на сервер и не сохраняются в браузере.

## Важное ограничение безопасности
Это **не настоящая система регистрации**. Проверки в браузере можно обойти. В проекте нет серверной части, базы данных, безопасного хеширования паролей, подтверждения электронной почты, управления сессиями, защиты от перебора или восстановления пароля. Не используй эту демоверсию для сбора реальных паролей и личных данных.

Чтобы реализовать настоящие аккаунты, подключи сервер или проверенный провайдер аутентификации. Сервер должен повторно проверять все поля, хешировать пароли современным алгоритмом (например, Argon2id), ограничивать попытки входа, безопасно управлять сессиями и не хранить секреты в публичном репозитории.

## Запуск
Открой `index.html` в браузере или включи GitHub Pages в настройках репозитория (**Settings → Pages**), выбрав ветку `main` и корневую папку `/(root)`.

GitHub Pages размещает статические файлы и сам по себе не обеспечивает серверную регистрацию пользователей.
